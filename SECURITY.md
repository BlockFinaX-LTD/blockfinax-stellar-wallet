# Security reports

Do not report a vulnerability or publish keys, personal data or exploit details in a public issue. Contact **hello@blockfinax.com** with the affected commit, reproduction steps and impact. This mailbox is the reporting contact; no response-time guarantee is stated.

This repository currently supports the Stellar testnet prototype. It has not been approved for customer funds or mainnet use. See `docs/threat-model.md` for implemented controls and remaining work.

If a credential is exposed, revoke and replace it immediately. Removing the file from the latest commit is not sufficient to remove it from history.
